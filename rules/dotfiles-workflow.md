Dotfiles (`.config/`, `.vscode/`, `.zshrc`, `.zshenv`, `.tmux.conf`) are symlinked from `~/dotfiles` via GNU Stow. Edit them in `~/dotfiles/`, never in `$HOME`, then `stow . --no-folding` from `~/dotfiles`. Commit and push the task's dotfiles changes before calling the work complete; stage only the task's changes and confirm the push.

Claude Code config (`settings.json`, agents, hooks, statusline) is not in dotfiles; edit it directly in `~/.claude/`. Secrets for Claude Code live in `~/.zshenv.local`, outside any repo; `settings.json` stays free of secrets.

Skills and rules are Skillfold-managed, also outside dotfiles. The manifest and lockfile are plain, unversioned files in `~/.config/skillfold/`. Personal sources live in `byronxlg/skills` (edit and push there); third-party sources come from upstream. Everything installed (`~/.claude/skills`, `~/.agents/skills`, `~/.claude/rules`, the managed block in `~/.codex/AGENTS.md`) is generated and never edited by hand. Use `skillfold add|update|remove|install -g`, finish with `skillfold check -g`. `skillfold --help` for the rest.
