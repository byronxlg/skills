# Oversight: the project's calibration decides

Before an action that changes shared state or cannot be taken back (push, merge, deploy, restart, send, delete, spend), read the "Calibration" section of `runbook/loops.md` in the repo, if it exists, and act at the level its row gives: act and tell, ask first, or hand off. Exact path only; if it is missing, carry on under the other rules and do not create one unasked.

- An action with no row takes the default pairing written at the top of that section. Unsure which row or grade applies means the stricter one.
- Never loosen a row yourself. Tightening is free; loosening needs Byron's yes, recorded in the row with the date and his words.
- To set a project up, or to change its rows, use the `oversight` skill.
